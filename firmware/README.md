# Custom Watchy firmware

Our watch face and apps, built on the forked Watchy library in `../src` (linked via `symlink://..`).
Default target: Watchy V3 (`watchy-v3`); `pio run -e watchy-v2` for V1/V2. Uses the [PlatformIO](https://platformio.org) CLI (`pipx install platformio`).

```sh
pio run                 # build
tools/flash.sh          # flash V3 (waits for the watch; press a button)
pio device monitor      # serial log
tools/sim/run.sh        # host tests + screenshots to ../extras/custom/*.png
```

## Layout

| File | What |
|---|---|
| `src/main.cpp` | `Face` (Watchy subclass): wake hooks, weather/steps, timer app input loop |
| `src/ui.cpp` | All drawing (face, timer screens, weather icons). No hardware calls, so the sim can render it |
| `src/timers.cpp` | Timer state in RTC memory |
| `src/weather.cpp` | Open-Meteo fetch (no API key) + 2-hourly view |
| `src/settings.h` | Location, weather interval |
| `src/fonts/` | Generated by `tools/fontgen.py` from Outfit (OFL, `tools/fonts/`) |

## Buttons

Back top-left, Menu bottom-left, Up top-right, Down bottom-right.

- Face: **Menu** = stock menu (Setup WiFi, Set Time, ...), **Down** = timers.
- Timers: Up/Down select, Menu = new timer / cancel the selected one, Back = exit.
- New timer: Up/Down change the value, Menu = next field / start, Back = previous field / cancel.

Timers wake the watch at their end time and vibrate. The face shows the 3 most recent.

## Notes

- First run: Menu > Setup WiFi, then join the `Watchy AP` network from your phone.
  Weather and NTP time sync every 30 minutes; the UTC offset (incl. DST) comes from the weather response.
- New font: `python3 tools/fontgen.py tools/fonts/Outfit-VariableFont_wght.ttf <px> <weight> <Name> [first-last hex]`.
  The '`' glyph renders as a degree sign.
- Library hooks we added in `../src/Watchy.h`: `onWake()` (every wake but first boot) and `nextAlarm()`
  (extra wakeup time, used for timer ends).
